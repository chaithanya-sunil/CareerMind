# 🧠 CareerMind — Offline AI Career Mentor

An offline AI-powered career mentor built with Ollama and Streamlit.
100% private — your data never leaves your laptop!

## Features
- 📄 Resume Analyzer (PDF/DOCX upload)
- 📊 Skill Gap Analysis
- 🗺️ Learning Roadmap Generator
- 📑 PDF Report Download
- 💬 Career Chat Assistant

## Tech Stack
- Python
- Ollama (LLaMA 3.2:3b)
- Streamlit
- FPDF2
- PyMuPDF

## How to Run
1. Install Ollama
2. Run: ollama pull llama3.2:3b
3. pip install -r requirements.txt
4. streamlit run app.py

## Model Performance
- LLaMA 3.2:3b: 23 tokens/sec
